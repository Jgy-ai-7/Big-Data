Hadoop is an open source framework for storing and processing big data in a distributed manner across clusters of computers. It uses simple programming models to process large data sets. The core of Hadoop consists of the Hadoop Distributed File System for storage and MapReduce for processing. Hadoop can scale from a single server to thousands of machines, each offering local computation and storage. The framework is designed to detect and handle failures at the application layer so that a highly available service can be built on top of a cluster of computers, each of which may be prone to failures. Today Hadoop is widely used by many organizations to analyze massive amounts of data and to build data warehouses and data lakes. The ecosystem around Hadoop includes tools such as Hive, Pig, HBase, and Spark, which make it easier to work with the underlying distributed storage and processing capabilities.
